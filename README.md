# Mophia

映像をリズムゲーム/インタラクティブアート作品に変換する体験筐体装置。

> Interactive game — 映像をリズムゲームにする体験展示
> 九州大学大学院芸術工学府 龍駿仁 / 井口朋也

来場者がスマートフォンから自分の動画をMophia筐体に送信すると、Mophiaがその映像を解析し、映像固有のUI・エフェクトを持つ音楽ゲームとして自動生成する。受動的な「視聴」だった映像を、能動的な「体験」に変える。
